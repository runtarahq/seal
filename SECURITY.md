# Security policy

## Reporting a vulnerability

Email **security@runtara.com**. Please do not open a public issue or pull
request for a suspected vulnerability.

Include what you found, how to reproduce it, and the commit or version it
affects. Do not send real credentials. Any test credentials you include should
be ones you have already revoked.

## Supported versions

The latest release and the `main` branch are supported. Report against either.

## Scope

[`docs/threat-model.md`](docs/threat-model.md) describes what seal does and does
not protect against. If you are unsure whether something is in scope, report it.
